# 实验自动中断与用户决策协议 v1

## 目的

本协议用于保证实验出现结果明显不佳、来源证据异常、运行故障或硬件安全风险时及时停止，并将会改变研究结论、实验协议、候选模型或资源投入的关键决定交给用户。协议适用于分类、开放集、鲁棒性、NAS、HLS/route、板级延迟与外部功耗实验。

## 中断等级

### S0：紧急安全中断

出现板卡、外部功率仪器、供电、温度、电流、电压或通信异常，且可能损坏设备或产生不可信数据时，立即停止当前硬件动作。安全中断不等待用户批准，但不得擅自改变硬件阈值；阈值必须来自板卡或仪器规格书以及用户批准的实验配置。

### S1：证据完整性中断

出现以下任一情况时立即 fail-closed（失败即关闭）：

- source freeze、代码状态、数据、划分、checkpoint、预测或配置 SHA256 不匹配；
- 训练或评测使用了未冻结划分、发生数据泄漏、样本 ID 不可配对或标签映射不一致；
- 主要指标出现 NaN、Inf、越界值，或者逐样本预测无法由 checkpoint 重建；
- HLS/route/bitstream/COM5/功率记录之间的候选、时钟、bitstream 或仪器来源无法绑定；
- 审计器失败、正式结果由手工修改而非生成器重建，或者中文档案出现乱码和结论冲突。

S1 触发后不得自动重试、替换输入或降低审计标准。

### S2：运行故障中断

出现 OOM、进程崩溃、持续工具链失败、磁盘空间不足、checkpoint 写入不完整、route timing 失败或硬件错误率异常时，在安全的原子边界停止。若继续运行会损坏设备或证据，则立即停止；否则完成当前不可分割的写入并保存 partial evidence（部分证据）。

### S3：性能或可行性中断

在预先声明的 pilot（小规模试验）检查点，根据用户批准的阈值判断是否暂停。阈值必须在实验启动前写入批准卡，至少包含：

- 主指标与方向：例如 macro_f1 越高越好、latency 越低越好；
- 对标方法与配对单位；
- 最小有意义差异或容忍差值；
- 检查点：epoch、fold-seed 数量、候选数量或 HLS/route 样本数；
- 判断规则：点估计、最差单元、配对置信区间、失败率或硬约束；
- 允许的动作：继续、仅补齐当前原子单元、诊断后再决定、终止当前候选。

未得到用户批准的性能阈值不得由执行代理临时补充，也不得因为结果不好而静默换模型、换 seed、换划分、扩大搜索空间或改变指标。

## 原子停止边界

- 分类：当前 fold-seed 的 checkpoint、记录和逐样本预测完成一致性写入后停止；若存在证据安全风险则立即停止并标记该单元无效。
- NAS：当前候选 evaluator 调用结束后停止；拒绝、失败与超时次数必须保留。
- HLS/route：保存已完成阶段报告后停止，不得把部分网络或旧 bitstream 伪装成当前完整网络结果。
- 板级延迟与功耗：完成当前可安全结束的采样 block 后停止；遇到 S0 时立即停止。

## 暂停档案要求

每次 S1–S3 中断至少保存：触发等级、时间、实验 ID、已完成/预期单元、最后安全原子边界、触发证据及 SHA256、运行进程状态、计划任务状态、正式证据增量、可选决策、恢复条件和禁止动作。人类可读档案必须为中文。

## 用户决策与恢复

恢复必须使用独立的机器可读批准文件，并同时满足：

1. 明确绑定暂停 manifest 的 SHA256；
2. 明确选择允许的动作与最大范围；
3. 不隐含授权更换候选、指标、数据、协议或 source freeze；
4. 恢复前重新核验 source freeze、当前进程、计划任务和所有输入；
5. 达到批准范围后再次自动暂停，不得继续进入下游阶段。

没有批准文件、批准文件与暂停 SHA 不一致、动作字段缺失或范围超出时，启动器必须退出且不运行实验。

## 当前 G1 应用

当前 `rl_arch_135` 在 14 个共同 fold-seed 单元上的 macro-F1 均值为 0.690453，从零训练 MobileNetV2 为 0.908091，ImageNet 预训练 MobileNetV2 为 0.930081，NAS 胜出 0/14。该结果已触发 S3 暂停；诊断未发现训练崩溃或权重加载故障，更支持容量与搜索空间限制。计划任务已禁用，匹配训练进程为 0，批准文件不存在。

当前恢复选择仍由用户决定：仅补齐 fold 4/seed 44 后再次暂停；保持暂停并诊断新方案；或废弃当前候选并在新协议与新 source freeze 下启动新实验。

## 证据边界

本协议不增加正式 T2–T9 或 F2–F12 证据，不替代用户的性能阈值决策，也不允许在当前 source freeze 下改变实验设计。

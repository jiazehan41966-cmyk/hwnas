# 最小算子改动提案：噪声感知局部残差（NAGR）

一页方案。依据：[分类证据表](CLASSIFICATION_OPERATOR_EVIDENCE.md) 与检测对照 `results/detection_controlled_20260912/`。不把分类 F1 写成检测定位证据。

## 1. 优先假设（三选一）

候选机制：局部细节保留、噪声感知门控、选择性上下文融合。

**优先：在恒等 Skip 上叠加「噪声感知门控的局部残差」（noise-aware gated residual, NAGR）。** 不把完整 CFEM、完整 DMDC 作为第一刀。

要解决的具体错误：

| 任务 | 已观测错误 | 假设中的机制 |
|---|---|---|
| 分类 | `fishing_net` F1 稳定约 0.28–0.31（n=20）；`small_propeller` 次之。现行正式代表在 28×28 槽位全是 Skip，中层纹理没有额外算子。 | 渔网是稀疏纹理，需要 **局部** 对比，而不是更大感受野把斑点与网纹混在一起。 |
| 检测 | 工作点漏检为主（valid cylider 召回 0.21，manta 0.07）；低阈值背景误检上千；定位误检远小于漏检。 | stride-8（检测 80×80 / 分类 28×28）细节不足导致漏检；无差别上下文融合（CFEM 式）可能放大背景纹理，加重误检。 |

历史旁证（协议不可与正式 DMDC/CFEM 并列，只约束方向）：旧 edge 降低分类 macro_f1；旧自适应降噪仅有未达显著的抗噪描述性优势。故 **拒绝「先上边缘增强或全上下文 CFEM」**。

## 2. 替换位置

- **只改分类/检测共用的目标槽**：分类 `stage[3]`，32 通道，stride=1。分类分辨率 28×28；检测 640 输入对应 80×80。其余 stem、MBConv 阶段、头、检测 neck/head **冻结**。
- 对照骨干：v3 `rl_arch_50`（Skip 槽，SHA `1bd2e0d9772dfa0e…`）。不得在未配对情况下更换其他阶段。
- 实现形态：`y = x + g(x) ⊙ F(x)`。`F` 为 1×1 → DW 3×3（dilation=1）→ 1×1，无空洞堆叠、无自适应区域池化、无 CBAM。`g` 为 3×3 局部方差/能量经 1×1 得到的单通道 sigmoid 门，值域约束到 `[0,1]`，初始化倾向关闸（残差近 0，退化为 Skip）。

相对现有算子：比 MBConv-k3e3 少 expansion=3；比 DMDC 少 dilation 1/3/5 与区域池化插值；比 CFEM 少三尺度空洞、尺度注意力与 CBAM。

## 3. 单因素对照（先分类，检测只在协议冻结后做同一槽）

同一骨干、同一划分、多种子；一次只改槽位。搜索代理不得当作正式表。

| ID | 槽位 | 回答的问题 |
|---|---|---|
| A0 | Skip（arch_50） | 基线 |
| A1 | MBConv-k3e3 | 「任意局部卷积」是否足够 |
| A2 | NAGR（本提案） | 门控局部残差是否优于无门控局部卷积 |
| A3 | A2 但门恒为 1 | 去掉噪声门；若 A3≥A2 则否定门控 |
| A4 | 推迟 | 完整 DMDC；仅当 A2 被否定且 LUT/DSP 仍有预算 |

禁止第一轮上完整 CFEM（DSP +452，LUT +13889，且与检测背景误检机制冲突）。

**分类协议（正式）：** `nksid_outer5fold_inner_contiguous_v1`，seeds 42/43/44，150 epoch，与 v3 重训相同。主指标 macro_f1、top1、`fishing_net` F1；不得用外层折选结构。

**检测协议（独立，后做）：** 仅 train/valid；固定 neck/head 与修复后的 objectness 归一化；主诊断为 **固定误检率下的召回**（已有 0.1/0.5/1.0 FP/图）及漏检 / 背景误检 / 定位误检分箱。AP75 或定位误检下降才能谈定位；macro_f1 不得填入该列。

## 4. 预期指标（预注册，不是已测结果）

在 A0 的 v3 数字上设最低可接受方向（未跑实验前不得写成已达成）：

| 指标 | A0 现状 | A2 预期方向 | 否定条件（任一即否定优先假设） |
|---|---|---|---|
| 分类 fishing_net F1 | 0.308 | 15 单元均值相对 A0 提升 ≥0.05，且 cylinder/floats 不下降 ≥0.02 | 渔网无提升，或多数类下降换来的 macro_f1 虚高 |
| 分类 macro_f1 / top1 | 0.853 / 0.932 | 允许持平；不得以 macro_f1 单独作为成功 | 仅 macro_f1↑而渔网与小螺旋桨不变 |
| 检测 valid 召回 @ 0.5 FP/图 | baseline 0.232 | 配对种子下相对 A0 提升，manta 漏检减少 | 分类变好但该召回不变或下降 |
| 检测定位误检 | 工作点远小于漏检 | **不预期** 作为第一效应 | 若只改善分类 F1 / AP50、定位分箱不变，**不得声称定位改善** |
| 硬件准入 | Skip 槽近 0 增量 | 见下一节；相对 A1 应更省 DSP/BRAM | 整网聚合突破现行硬限制且无更小实现 |

A1 ≥ A2 且 A3 ≥ A2：否定「门控」，只保留局部卷积。A2 伤害干净图、只在合成斑点上变好：假设缩成抗噪，不能写任务精度。

## 5. 额外计算 / 存储开销（相对 Skip 槽，算子级 LUT）

按 v3 表目标槽与结构类比（NAGR 尚无独立 HLS 行，下表 **预算上界用 MBConv-k3e3 行**，预期低于该行）：

| 项 | Skip | MBConv-k3e3（A1 实测行） | NAGR 预算上界 | CFEM（明确不采用） |
|---|---:|---:|---:|---:|
| latency_ms @200 MHz | 0.002 | 3.359 | ≤3.359（无 e=3 扩展，预期更低） | 11.324 |
| LUT | 330 | 4891 | ≤4891 | 14219 |
| DSP | 0 | 12 | ≤12 | 452 |
| BRAM tile | 0 | 59.5 | 目标 ≪59.5（无大缓冲展开） | 35 |
| 软件 MACs（量级） | 0 | 扩展×DW×投影 | 约 32×32×1×28² + 32×9×28² + 32×32×1×28²，无三分支 | 三空洞 + 注意力 |

参数：门控 1×1 为 32→1，残差无 channel expand。相对 DMDC 去掉 3 分支 dilation 与 `AdaptiveAvgPool + interpolate`（后者当前整数参考仍未闭合）。整网是否可布线仍要单独 HLS；本提案不声称板级可行。若实测 NAGR 资源超过 A1，方案失败，回退 A1 或放弃槽位改动。

现行 312 BRAM tile 与 LUTRAM 代理已使「Skip + 现行其余阶段」代表越界。槽位实验必须 **冻结其余阶段** 并单独报增量，不得把历史 476–520 tile 的 Skip 网当作可部署基线。

## 6. 验收对照

| 必须同时具备 | 本方案对应 |

| 检测诊断 | 漏检与背景误检主导、定位非主因；分类 F1 不作为定位证据 |

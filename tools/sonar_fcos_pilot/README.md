# 声呐目标检测：第一轮独立试验

本试验只回答：不同大小的特征图，是否需要查看不同范围的图像信息。
原有网络、原有训练结果和数据划分均保留。本目录不导入原有网络或评价器。

## 当前可交付内容

- UATD（公开前视声呐目标检测数据）来源校验、逐图标注检查、数据划分接口和示例图。
- FCOS（直接预测目标类别和位置的检测方法），使用 ResNet-50（提取图像特征的主干）和 FPN（联系不同分辨率特征的特征金字塔）。
- 八种网络组合；只有三个既有特征处理层能选择普通或扩张卷积。
- 30 轮训练、保存进度、验证集挑选方案、三个随机编号重复确认、最后才使用测试集。
- mAP（平均检测精度）使用 COCO（通用目标检测评价所用的公开图像数据集）的标准，在从宽松到严格的十种目标框重叠要求下计算成绩，范围为 0—100；不是旧项目的两个精度指标平均。
- 漏检、误报、框偏移数量；小目标找到的比例；错误示例图和中文结果报告。

## 数据必须先通过核验

“采集序列”是同一次连续拍摄的一组图片。它的作用是让几乎一样的相邻帧进入同一数据部分，减少网络靠记住图像取得好成绩的风险。
图片编号本身不能证明采集序列。严格接口要求对应记录注明来源证据，而且至少能形成两个独立开发组。

当前实际核验：官方训练 7600 张，官方测试 1600 张；四个原始压缩包均与公开来源校验值一致。
公开 XML（保存目标类别和框位置的标注文件）没有真实采集序列对应关系。另有 16 个不合法框，涉及 15 张图。
原始数据不改写，不把异常目标直接删除成“背景”。数据未通过时，程序会生成检查报告，并阻止正式训练。

相似图像审计只是替代方案的预览，不能当作真实序列证据。当前相似规则把近七成开发图连成一个大组，验证类别分布很不均衡，不直接采用。
相似分组方案和非法标注的处理需另行确定，不能把当前预览包装成已经通过的数据划分。

另有 `draft` 命令可以生成“探索性划分”草稿：按类别尽量均衡地分出验证数据，整张留出含非法框的图，原始数据不修改。
草稿明确说明没有真实拍摄序列隔离、官方测试仅评价有效标注子集，不能用来声称新场景识别能力。用户明确确认前，草稿不会被训练程序接受。
只有明确接受这一调整后，才使用 `accept-exploratory --confirm-protocol PUBLIC_SPLIT_EXPLORATORY_V1` 保存确认记录；该命令仍不启动训练，而是给出单独的配置文件路径。

## 网络中允许改变什么

三个位置依次对应细、中、粗三种分辨率的特征；原网络的其他层仍保留。

| 选项 | 中文解释 |
|---|---|
| A | 普通 3×3 卷积，查看连续相邻的九个位置 |
| B | 扩张率为 2 的 3×3 卷积，隔着位置采样，覆盖更大的范围 |

组合是 AAA、AAB、ABA、ABB、BAA、BAB、BBA、BBB。
三处替换原有处理方式，不额外加层。同一个随机编号内，所有组合初始参数、参数数量、输出尺寸一致。
网络的参数（训练时学到的数字）正常学习，不是把整个网络冻结。
模型仍保留官方的五个检测层，三个可选位置不表示整个网络只有三个层。

## 公平比较与判断规则

- 图像保持比例缩放并补齐 640×640；每个方案学习 30 轮，一轮指完整学习一次训练数据。
- 本机每次处理 1 张图，累积 4 张图的调整量后再更新参数；所有组合有效每批数量均为 4。
- 使用相同公开初始参数。学习率（每次调整参数的步幅）0.0025，完成第 20、25 轮后，后续步幅各降为十分之一；第一轮逐步增加步幅，避免刚开始不稳定。
- 首轮八种组合共用随机编号 42。验证集选出一个组合，再与 AAA、BBB 使用 42、43、44 比较；重复方案合并，最多 14 次正式训练。
- 最佳训练轮次和网络组合都由验证集确定。测试集要等八种首轮训练和全部重复训练完成后才用于最后评价。
- 小目标界线只用训练目标框计算：目标框占原图面积比例最小四分之一的边界；补边后的面积和测试目标不参与界线计算。
- 漏检和误报的判断分数先在验证集选择：平均每十张图最多一次误报时，尽可能多找到目标；框偏移预测和剩余误报都计入这项预算。测试时固定这个分数，并报告实际误报数。
- 普通诊断用预先固定的 0.25 判断分数，与前述误报控制结果分别保存。正确类别且框重叠比例不低于一半为找到目标；同类别且重叠一至五成为框偏移，采用一对一配对；其余标注为漏检，其余预测为误报。错类别可能同时造成一个漏检和一个误报，不把这套简化规则冒称其他论文的完整诊断工具。
- 通用平均检测精度使用全部预测分数，固定模型内部最低分数 0.001 和每图最多 100 个结果；类别 0 为背景，导出检测结果时排除。
- 混合方案的三次平均成绩比两个统一方案都高至少 1 个百分点，至少两个相同随机编号下都有提升，小目标检出比例高于两个对照，误报不超过两个对照中较高的水平，才写“初步支持”。
- AAA 被选中则保留普通卷积；BBB 被选中只检验扩大查看范围；其他结果记录为证据不足。不自动扩大第二轮搜索。

## 怎样运行

在仓库根目录使用已有虚拟环境（本项目专用的 Python 和依赖组合）。以下命令不含服务器密码。

```powershell
.\.venv_cuda\Scripts\python.exe -m tools.sonar_fcos_pilot.run environment
.\.venv_cuda\Scripts\python.exe -m tools.sonar_fcos_pilot.run prepare
.\.venv_cuda\Scripts\python.exe -m tools.sonar_fcos_pilot.run status
```

`prepare` 返回编号 2 表示数据门槛未通过，不是正式训练失败；具体原因见数据核验报告。
有真实对应记录时可使用 `prepare --group-map 对应记录文件路径`。来源证据要求见生成的 `group_map_template.json`，仅填写组名不能使标注异常自动通过。

数据通过后，执行有限训练流程：

```powershell
.\.venv_cuda\Scripts\python.exe -m tools.sonar_fcos_pilot.run campaign
```

程序先训练 AAA，再决定方向；框偏移数量超过漏检与误报之和时停止。中断时从最后完整轮次恢复；源码、配置、数据、运行环境、组合或随机编号变化时拒绝复用结果。
完整结果存入 `results/sonar_fcos_pilot_20261008`；大权重存入 F 盘 `sonar_fcos_pilot/checkpoints/20261008`，源码和结果校验值均有记录。

查看数据问题：`results/sonar_fcos_pilot_20261008/data_audit/数据核验说明.md`。
查看相似分组限制：`results/sonar_fcos_pilot_20261008/similarity_review/相似分组预览说明.md`。
服务器准备命令另见本目录 `README_remote.md`；准备完成不等于正式训练完成。

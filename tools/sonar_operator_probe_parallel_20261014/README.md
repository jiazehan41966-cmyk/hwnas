# 算子实验并行资源修订 2026-10-14

用户明确要求使用其他可用 GPU 并行运行。此目录是原冻结算子实验的附加执行入口，原模型、数据、损失、优化器、80 轮训练协议、seed42 初筛、seed43/44 确认、验证集选择及封存测试集均沿用原执行清单。

GPU1 沿用独占调度；GPU2/3 与身份固定的驻留语音服务共享空闲显存，每卡最多一个本实验工作进程。GPU0 不参与本次资源修订。任何陌生计算进程出现、驻留进程身份改变、显存不足或入场利用率过高都会阻止新增任务。不会终止驻留服务。

新 wrapper 只替换原 runner 的物理 GPU 识别和资源入场函数。资源修订、wrapper SHA256、实际 GPU UUID、原清单 SHA256、原完成任务导入凭据与并行工作进程均单独记录。原 21 个真实烟测提供模型可运行性和最大显存依据；GPU2/3 各一次控制组真实烟测验证新槽位迁移，不能替代正式 80 轮结果。

旧 CPU dispatcher 停止后，已启动的 GPU1 子进程继续运行并在完整验证完成后导入。唯一任务 claim 和 scheduler 文件锁防止重复运行；失败不自动重试。48 GPU 小时上限按各工作进程的时间相加计算，资源累计等候上限 6 小时。

远端新执行入口使用原凭据安全 SSH 桥接，网络上传仅包含新源码和执行凭据。完成任务的 checkpoint 在服务器内复制到新结果目录，并核验字节 SHA256。生成证据在 `results/sonar_operator_probe_parallel_20261014_01/`。
